03　窗口管理：分屏，不用再拖来拖去
macOS 自带分屏要长按绿按钮、再选另一半，窗口一多就手忙脚乱。

这里简单得多：自动识别当前所有窗口，勾选两个 → 左右平分或上下平分，一步到位。还有「单窗口快捷」：左半屏、右半屏、居中、置顶，点一下排好。

顺带一提，工具自己的面板会被自动排除——不会出现把工具栏自己分屏了的尴尬。

应用双开

04　应用双开：很多人装它的理由
工作号一个微信，生活号一个微信——以前要么折腾副本，要么装虚拟机。

但这里有个坑必须说清楚：不是所有 App 都吃「多开」这一套。

macOS 上最常见的做法是系统自带的open -n，秒开、不占磁盘。问题是——微信不吃这一套。微信带单实例保护，open -n确实能拉起第二个进程，但它会在0.9 秒内自己退出。QQ、Telegram 这类可以用，微信不行。

所以 Mac Bar 控做了两种模式，把这件事兜住：
•标准模式：走系统open -n，秒开、不占磁盘。QQ、Telegram 这类应用够用

•强制模式（重点）：生成一份独立副本再打开，直接绕过 LaunchServices 的单实例限制——微信这类有保护的应用必须用它，其他任何 App 也都能用

至于「复制一份 App 会不会很占地方」：强制模式会优先复用已有的空闲副本，能秒开就不新建；实在没有才创建一份。开了几个、各占多少空间，面板上都实时显示。

多开副本与原程序数据相互独立，可以分别登录不同账号。

三种力度随便选，恢复也是一键的事


07　屏蔽系统更新：分三种选择，看你想挡多严
老 Mac 一升级新系统就变卡、Xcode 只兼容特定版本、工作环境要求版本固定——很多人都想「把系统更新摁住」。但「摁住」也分想挡多严：

•只断大版本（推荐）：只拦大版本安装器的下载地址。小更新照常装，安全补丁一个不落；大版本点了也下不动，系统安静地留在你现在的版本上

•彻底断源：连「更新检测」的服务器一起拦——软件更新页面直接显示「无法检查更新」，大版本入口彻底消失，连弹窗提醒都没有

•连 App Store 一起拦（默认关）：最彻底的一档，大版本下载彻底挡死；代价是 App Store 的下载和更新也会失效——所以它默认关闭，要不要用你自己决定

为什么「只断大版本」是默认推荐？
大版本带来变卡和兼容问题，而安全补丁恰恰藏在小更新里——挡大版本、放小更新，才是多数人真正想要的。
另有独立的「系统不自动更新」开关：关掉后台的自动检查、下载与安装，想升级时手动去「软件更新」点一下就行。

实现方式是改/etc/hosts把更新域名指向本地，开启时输入一次管理员密码，恢复同样是一键的事，随时可逆。
